# Digital Heritage Archive for Memorials, Manuscripts & Ambedkar (SIH26096)

Smart India Hackathon 2026 project — see [`heritage-archive/README.md`](./heritage-archive/README.md)
for the backend (FastAPI, Postgres/PostGIS, Qdrant, ingestion pipeline, RAG engine).

## Frontend (this repo root)

This is a [Next.js](https://nextjs.org) app bootstrapped with `create-next-app`.

\`\`\`bash
npm install
npm run dev
\`\`\`

Open [http://localhost:3000](http://localhost:3000). The frontend expects the backend
running at `http://localhost:8000` (see `heritage-archive/backend/`).

Learn more: [Next.js Documentation](https://nextjs.org/docs).
